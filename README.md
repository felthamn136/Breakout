# Breakout

A classic Breakout-style arcade game built with Python and Tkinter.

## Features

- 800 x 600 game area using a 4:3 aspect ratio
- Five rows of 50 total bricks
- Score and remaining lives displayed in the HUD
- Paddle deflection based on hit position
- Increasing ball speed as bricks are destroyed
- Serve, game over, and win states
- Mouse and keyboard paddle controls
- CRT-style scanlines

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

## Run

From the project directory:

```powershell
python "breakout.py"
```

## Controls

- **Left / Right Arrow:** Move the paddle
- **Mouse:** Move the paddle
- **Space or Left Click:** Launch the ball
- **Space:** Restart after a game over or win
